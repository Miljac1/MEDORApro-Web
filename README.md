# MEDORApro – službena najavna web-stranica

Statična, responzivna HR/EN stranica. Bez vanjskih biblioteka, kolačića i analitike.

## Objavljivanje na GitHub Pages
1. Na GitHubu otvorite novi **Public** repozitorij `MEDORApro-Web` (odvojen od privatnog Android repozitorija).
2. Dodajte `index.html` i `.nojekyll` u korijen repozitorija.
3. Otvorite **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Odaberite **main** i **/(root)** pa **Save**.
5. Adresa će biti `https://miljac1.github.io/MEDORApro-Web/` ako je vlasnik repozitorija `Miljac1`.

## Prije promocije
- Mockup telefona na naslovnici **ilustracija je**, nije stvarna snimka MEDORApro. Zamijeniti stvarnim zaslonom aplikacije (bez osobnih podataka).
- Provjeriti završne marketinške tvrdnje i pravne informacije prije službenog lansiranja.
- Kasnije se može povezati vlastita domena u postavkama Pages.
