# MEDORApro Web — PREMIUM v2

Službena najavna stranica, statična, bez baze podataka ili analitike.

## Objavljivanje na GitHub Pages

U repozitorij `Miljac1/MEDORApro-Web` učitajte sadržaj ove mape u korijen grane `main`: `index.html`, `styles.css`, `script.js`, `.nojekyll`, `README.md` i mapu `assets/` sa slikama. Otvorite Settings → Pages → Deploy from a branch → main → /(root).

**Napomena:** Medijski materijali uključuju ilustrativne AI promotivne kompozicije, a ne izvorne snimke zaslona. Ne prikazivati Family kao dovršen proizvod. Testna verzija 1.2.52 nije prikladna za stvarne medicinske podatke jer lokalni zapisi nisu šifrirani u mirovanju.

Projekt ne utječe na privatni Android repozitorij.
